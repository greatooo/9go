# 9go（Mandala 九宫格）

基于 `gogoga-mindmap` 的**笔记大纲语法**、独立实现的新 Obsidian 插件。
不修改原插件，两者可同时启用（视图/命令 id 全部使用 `9go-` 前缀）。

> English: [README.en.md](README.en.md)（说明） · [CHANGELOG.en.md](CHANGELOG.en.md)（更新日志） · 中文更新日志 [CHANGELOG.md](CHANGELOG.md)

## 为什么是独立实现

`gogoga-mindmap` 在库内只有 esbuild 编译产物 `main.js`（约 850 KB / 19,745 行，无 TypeScript 源码、无 sourcemap），且视图类型、命令 id、代码块名都硬编码为 `gogoga-mindmap`。整包复制会与它抢同一批注册项。因此 `9go` 采用**语法兼容 + 独立视图**：沿用同一套「标题/列表/Tab 备注/`%%标记%%`」数据模型，但用全新 id，互不干扰。

## 九宫格规则

```
        [8] [1] [2]        1.1  1.2  1.3
        [7] [C] [3]   →    1.4   C   1.5
        [6] [5] [4]        1.6  1.7  1.8
```

- **中心格** = 当前中心节点，默认取**笔记标题（文件名）**；显示标题、备注和「返回上级」。备注与环绕格一样跟随「默认显示备注」设置（v1.3.1 起），也可点右下 `⌄/⌃` 单独覆盖。
- **环绕 8 格** = 中心节点的下一级节点，从**正上方为第 1 个**，**顺时针**排列；左上角为第 8 个。
- 层级映射：笔记标题 → `# 一级`（环绕）→ 点左下「下级 N」进入某个 `# 一级` 后以它为中心，`## 二级` 成为环绕 → 依此类推；列表项作为更深层的节点。
- 每格（**含中心格**）第一行是节点核心词；备注默认隐藏，可在设置里全局打开，或点格子右下角 `⌄` 单独展开/收起。中心格的点按会临时覆盖全局设置，下钻到下一级后重新跟随设置。
- 右上角 `1.1`–`1.8` 是格位标签（与参考图一致），不是子节点序号。

## 排列方位与层级编号（v1.2.0）

### 第 1 个节点的位置 + 排序方向

设置里可选第 1 个子节点落在**上 / 下 / 左 / 右 / 左上 / 右上 / 右下 / 左下**任一环绕格，以及**顺时针 / 逆时针**填满其余格位。默认「正上方 + 顺时针」，与 1.1.0 一致：

```
        [8] [1] [2]
        [7] [C] [3]
        [6] [5] [4]
```

改成「左上 + 顺时针」后，第 1 个节点移到左上角，序列左上角起顺时针绕行；改成「正上方 + 逆时针」则第 2 个落在左上角。**格子左上角的编号始终跟着第 1 个节点的位置与方向走**。

环序列基于两条纯函数生成的环：`RING_CW`（正上方起顺时针）与 `RING_CCW`（同起点逆时针），`buildSlots(firstSlot, direction)` 从锚点旋转切片得到 8 个格位。

### 编号规则（对应 Markdown 标题层级）

| 当前环绕层 | 例（标题） | 编号 |
|---|---|---|
| 一级 | `# 一级1` / `# 一级2` / `# 一级3` | `1` / `2` / `3` |
| 二级（在 1 下） | `## 一级1下面二级1` … | `1.1` / `1.2` / `1.3` |
| 三级（在 1.1 下） | `### 三级1` … | `1.1.1` / `1.1.2` / `1.1.3` |
| 四级及以上 | 第 4 级 `1.1.1.1` | `1...1.1` |

超过 3 层时压缩为「**首段 + `...` + 末两段**」，即最开始的一级序号、3 个点代表省略号、再接「上一级的末段序号 + 本级序号」。例如 `1.1.1.1` → `1...1.1`。中心格左上角显示当前中心节点自身的编号（同样压缩）。

编号是**全局同级序号**：翻到第 2 页继续 `9`、`10`…（或 `1.9`、`1.10`…），不会每页从 1 重来。右上角固定的 `1.1`–`1.8` 格位坐标标签默认关闭，可在设置里打开（避免两套编号混淆）。

## 拖动调整同级顺序（v1.2.0）

拖动任意已填充子节点格，放到**同级两个格子之间**：靠近目标格的左半 / 上半区 = 插到它前面，右半 / 下半区 = 插到它后面。放置时目标格显示 L 形插入指示线与高亮边框。

放下后，`reorderChildren` 把每个直接子节点连同**整段子树 + 备注 + 空行**按新顺序重组，并通过 `vault.modify` 写回 Markdown；重绘后编号、下钻层级与页码自动按新顺序更新。拖动整段而不是只改标题，父子关系不会断。空格也可作为放置目标（等价追加到该位置）。内嵌 ` ```mandala ` 代码块没有可写文件，不启用拖动。

## 光标跟随：分屏 MD 编辑时自动切换中心（v1.3.0）

设置里打开「光标跟随 · 分屏 MD 编辑时自动切换中心」后，插件每 **250ms** 读取活动 Markdown 视图的光标行（只读 `editor.getCursor()`，不改文档、不抢焦点），把**同一笔记**的九宫格视图调整为：

1. 找到光标之前最近的标题/列表节点（`findNodeAtLine`）——光标停在该节点的备注、空行或正文里也算它；
2. 以该节点为**中心节点**，环绕格显示它的子节点；
3. 给该节点所在的格子加焦点高亮，工具栏显示「⌖ 跟随光标」。

若光标所在节点**没有下级**，按设置「光标所在节点没有下级时」处理：

| 选项 | 行为 |
|---|---|
| 回退到父级并高亮该格（**默认**） | 以父节点为中心，翻到包含该节点的页，高亮该节点所在格；叶子节点也能看到自己的同级 |
| 仍以光标节点为中心 | 严格以光标节点为中心，环绕 8 格为空，中心格显示「（无下级节点）」 |

实现上刻意**不 import `@codemirror/view`**：用插件级 `registerInterval` 轮询活动 `MarkdownView`，避免 CM6 符号缺失导致整个 `main.js` 加载失败。光标行未变化时不重绘；单击九宫格定位 MD 后，光标行变化会反过来让九宫格自动切到该节点，两者不会互相抢焦点。

九宫格内手动下钻 / 翻页 / 展开备注走的是 `grid.render()`、不重建视图，因此**不会被跟随拉回**；只有 `vault.modify` 重绘或改设置时才按当前光标重新定位。重绘时导航路径除按标题外还会按**绝对行号**恢复（`getStackLines` / `applyNavigation` 第三参数），所以编辑节点改了标题后仍能停在原来的下钻层级。

## 交互分工与编辑已有节点（2026-11-10 调整）

交互分工已固定，不再提供设置开关：

| 手势 / 元素 | 行为 |
|---|---|
| **双击标题区域文字（无下级的叶节点）** | 以该节点为中心进入九宫格（空九宫可继续双击空格加子节点） |
| **双击标题区域文字（有下级的节点）** | **不响应**——下级统一走左下「下级 N」单击进入 |
| **单击节点空白区域** | 保留：在分屏 Markdown 中定位并高亮该节点 |
| **双击节点空白区域** | 打开「标题 + 备注」编辑框，写回 Markdown |
| **点左下「下级 N」** | 进入下一级九宫格（取代原 `⤵` 图标，该图标已移除） |
| **点右下 `✎`** | 与双击空白处等价，编辑入口保留 |
| **点右下 `↗` / `⌄`** | 强制在 MD 中定位 / 展开收起备注 |
| **双击空白格** | 新建子节点 |

编辑框（编辑模式）：**不再显示顶部「编辑节点」大标题**，第一行直接是「标题 + 输入框」，其下「备注 + 多行输入框」，最下面才是可折叠的「编辑说明」（默认收起）。标题/备注两个输入框沿用强调色边框突出显示。

- 标题：必填。**未修改时原行逐字节保留**（wiki 链接、粗体、`%%标记%%`、`^块id` 都不丢）；修改后保留 marker（`# ` / `## ` / 列表缩进与项目符号）以及行尾 `%%标记%%` / `^块id`。
- 备注：可多行，保存时按「新建节点 · 备注写法」的设置重写（默认 `> ` 引用块）。**列表节点的备注自动缩进一层**（`\t> `），避免顶格引用块打断列表、使下级无序列表在阅读模式里退化成 `- ` 纯文本；标题节点备注仍顶格。
- 写回只改**该节点自己的备注区**（标题行之后、第一个子节点或 section 结束之前）：跳过围栏代码块、水平线、结构行与空行；**下级标题子树、兄弟节点、frontmatter、CRLF 全部不动**。
- 清空备注框即可删除该节点的备注；内容无变化时不写盘。

**根中心（笔记标题/文件名）没有对应的 Markdown 行，不可编辑**，会给出提示。内嵌 ` ```mandala ` 代码块没有可写文件，也不提供编辑。

## 双击空格：新建子节点（v1.1.0）

环绕格中**没有节点**的空格会显示「+ 双击添加」。双击后弹出的输入框与**编辑节点完全同构**（无大标题、说明折叠在最后）：「标题 + 输入框」在前，「备注 + 多行输入框」居中，最下面是可折叠的「新建说明」（默认收起）；**光标自动定位到标题输入框**：

- **标题**：必填，新节点的核心词。
- **备注**：可多行，每行一条；默认写成 `> ` 引用块（可在设置里改为普通段落）。列表节点的备注自动缩进一层，不打断下级列表。

确定后按**当前九宫格层级**写回当前笔记：

| 当前中心 | 新节点写法 |
|---|---|
| 笔记标题（根） | `# 标题` |
| `# 一级A` | `## 标题` |
| `## 二级A1` | `### 标题` |
| 列表项 | 同缩进的列表项 / 更深一级列表项 |

插入位置是**当前中心节点 section 的末尾**（下一个同级或更高级标题之前），即追加为最后一个子节点；因为 Markdown 是线性的，双击哪个空格都追加到末尾，弹窗里会说明它将落在哪个格位。

写入用 `vault.modify`，随后的 400ms 防抖重绘会**保留当前下钻层级与页码**（1.1.0 起），不会跳回根九宫格。内嵌 ` ```mandala ` 代码块没有可写的文件，因此不提供此功能。

## 单击节点：分屏 Markdown 定位 + 高亮（v1.1.0）

**单击中心格或任意子格**（不点在链接/按钮上）时：

1. 查找同一笔记的 Markdown 视图（分屏窗格或后台标签）；
2. `setCursor` + `scrollIntoView` 跳到该节点对应的行（标题级别自动对应）；
3. 给该行加 `enm-locate-flash`，用 Obsidian 搜索结果的高亮色 `--text-highlight-bg` **按设置时长保持高亮**（默认 1400ms，范围 300–10000），到点再淡出约 220ms；时长由 JS 单一 deadline 控制，CodeMirror 重建行 DOM 时会自动补回高亮（见「2026-11-11 第六轮」）；
4. **不抢焦点**——九宫格保持可点，连续单击可持续驱动 MD 窗格。

单击与双击用 230ms 延时区分：双击会取消待执行的定位（叶节点双击标题下钻、双击空白处编辑）。格子右下角 `↗` 是「强制在 Markdown 中打开并定位」（新标签）。

若找不到同一笔记的 Markdown 视图，按设置「无分屏 Markdown 时」处理：自动分屏 / 新标签 / 不处理。阅读模式下若拿不到 CodeMirror 行，会按标题文字匹配可见标题元素来高亮。

## 分页（> 8 个同级节点）

- 每页 8 个；**序列末格（第 8 格，默认左上角）无论有无内容都常驻「**更多子节点**」链接**：有下一批真实子节点时显示实际范围（如 10 个子节点 →「更多子节点 (9–10)」），没有时显示整批范围（如 3 个子节点 →「更多子节点 (9–16)」）。点击进入下一页（第 9–16 个）的**编辑显示页**——该页 8 格均为可双击新建的空格，仍从正上方顺时针排列。
- **新建子节点永远按顺序追加**：前面的格子未满 8 个时，双击任何空格（包括第 9–16 编辑页的空格）新建的节点都排在**最后一个有内容的节点之后**，不占用「更多子节点」格。
- 第 2 页起，末格同时出现「**返回**」，点击回到上一页；超过 16 个继续按此逻辑翻页；工具栏另有 `‹ 1/3 ›` 翻页按钮（最多可到真实页数 +1 的虚拟空页）。

## 触发方式（关键词 `mandala`，可在设置里改/加）

| 方式 | 写法 |
|---|---|
| frontmatter | `mandala: true` 或 `mindmap-structure: mandala` |
| 行内标记 | `%%mandala%%` |
| 内嵌代码块 | ` ```mandala ` 块内写同样的 Markdown 大纲 |
| 命令面板 | 「以九宫格（Mandala）打开当前笔记」/「九宫格：把当前标签切换为 Mandala 视图」 |
| 文件右键 | 「以九宫格（Mandala）打开」 |

### 两个可绑定快捷键的命令有什么区别

快捷键设置页里这两条都指向同一个视图类型 `9go-mandala-view`、绑定同一篇笔记，**唯一差别是「新开标签」还是「替换当前标签」**：

| 命令（id） | 行为 | 适用场景 |
|---|---|---|
| 「以九宫格（Mandala）打开当前笔记」(`9go-open`) | `getLeaf("tab")` **新开一个标签**显示九宫格，原 Markdown 标签原样保留 | 需要分屏联动：一个标签点九宫格、另一个标签看 MD 定位高亮 |
| 「九宫格：把当前标签切换为 Mandala 视图」(`9go-replace`) | 对当前 `activeLeaf` 调 `setViewState` **就地替换当前标签**，原 Markdown 视图不再作为独立标签存在 | 只想把当前笔记换成九宫格读图，不想多开标签 |

- 文件右键菜单「以九宫格（Mandala）打开」= 新标签（同 `9go-open`）；自动打开（关键词命中）= 就地替换当前标签（同 `9go-replace` 的效果）。
- 用 `9go-replace` 且原本没有其它 MD 标签时，单击定位会按设置「无分屏 Markdown 时」自动分屏 / 新标签打开 MD；用 `9go-open` 则天然已有分屏可联动。
- 两者都不改动笔记内容；`setViewState` 后可用 Obsidian 的返回导航回到 Markdown 视图。

自动打开：设置默认开启，打开带关键词的 Markdown 笔记时把该标签切换为九宫格（每个文件每次会话最多一次，避免来回切换循环）。

## 构建

源码在 `999其他文件/9go/`（该目录由 Syncthing 同步，可跨机迁移）：

```bash
cd "E:/OObsidian/999其他文件/9go"
node build.js
# 或指定输出目录
NINEGO_OUT="E:/OObsidian/.obsidian/plugins/9go" node build.js
```

产物落到 `.obsidian/plugins/9go/`：`main.js` / `manifest.json` / `styles.css`。
`build.js` 同时生成 `.core-test-bundle.cjs`（parser + layout）供 Node 侧回归测试。

## 部署后

1. 完全退出 Obsidian（右键托盘 → Quit）再重开——Obsidian 不会自动重载插件 `main.js`。
2. 确认插件已启用：本机启用清单看 `lazy-plugins/data.json` → `desktop.plugins.9go.startupType`；`community-plugins.json` 需**增量追加** `"9go"`，禁止整体重建。

## 已知限制

- 备注以纯文本显示（**v1.3.2 起图片是唯一例外**：图片语法从原始行抽出后渲染成 `<img>` 缩略图，其余 Markdown 仍不渲染），wikilink 会显示别名文字、不可点击；这样避免 XSS 与异步渲染开销。缩略图不解析 HTML、不执行脚本，`[[笔记#^块ID]]` 只读取目标块第一张图、不递归。
- 节点修改后由 `vault.on("modify")` 400ms 防抖重绘；1.3.0 起优先按**绝对行号**、再按标题路径恢复下钻层级与页码。若同时插入/删除了行导致行号整体偏移，仍可能回退到能匹配的最深一层。
- 光标跟随基于 250ms 轮询**活动** Markdown 视图：切到别的笔记、MD 视图不是活动叶子、或阅读模式拿不到 `editor.getCursor()` 时会暂停跟随。
- 编辑节点时，备注框显示**原始写法**（图片链接、`![[附件]]`、`[[笔记#^块ID]]`、块 ID、`%%标记%%` 均可直接改或删，v1.3.2 补丁起）；备注未改动时整段原样写回，围栏代码块、水平线与结构行不会动。只有主动改动了备注内容，备注区内的普通正文 / 表格 / HTML 注释才会按当前风格（`> ` 引用块或段落）一起重写；有必须逐字保留的格式时请直接在 Markdown 中修改。
- 新建节点只能追加为当前中心的最后一个子节点；Markdown 无「空洞格位」概念，若要精确落到某个格位需手动调整笔记顺序。
- 单击高亮依赖 CodeMirror 的 `.cm-line`；阅读模式或第三方编辑器主题下会退化为按标题文字匹配，可能不精确。第六轮起有 50ms 守护可应对 DOM 重建，但若目标行滚出视口（CM6 不再渲染该行），守护会等它重新出现，期间不显示高亮。
- 拖动只在**当前页可见**的同级节点之间生效；跨页移动需先翻页或改用 Markdown 原文调整。
- 拖到中心格上升一级后，节点落在中心**所有兄弟的最后**（中心整段之后）；要在某兄弟之前需再做一次同级拖动重排。
- 超过 3 层的编号压缩是有损的：不同深层路径可能显示相同的 `首段...末两段`（如 `1.1.1.1` 与 `1.2.3.4` 的前后段相同时），需要精确定位时看面包屑或下钻到该层。
- 序列末格（默认左上角）无论有无内容都常驻「更多子节点」链接（v1.3.1 行为）；改变首节点方位后，它随序列移动，不再固定在左上角。
- 本机无法启动 Obsidian，交付前只做解析器单测 + DOM 级回归 + esbuild 真打包；真实渲染需用户重启实测。
