# 9go — Mandala（九宫格）视图 for Obsidian

把任意 Markdown 大纲摊成一张 **3×3 九宫格**：中心是当前节点，周围 8 格是它的下级。
按 `Tab` / `Enter` 就能在九宫格里往下写、往下钻，写回去仍然是干净的 Markdown 标题与列表。

- 语法与交互参考 **[gogoga-mindmap](https://github.com/JackWeiGogoga/gogoga-mindmap)**，按同一套数据模型**独立实现**，两个插件可同时启用、互不干扰（视图类型、命令 id、代码块名全部用 `9go-` 前缀）。
- 视图内新建 / 编辑 / 拖动 / 定位均直接写回 Markdown 正文，不引入私有格式。
- 当前版本 **1.3.1**（`minAppVersion` 1.8.7）。

## 安装

### 方式一：手动安装（两步）

1. 从 [Releases](https://github.com/greatooo/9go/releases) 下载最新版的 `main.js`、`manifest.json`、`styles.css`；
2. 放到 `<你的库>/.obsidian/plugins/9go/` 目录下（没有就新建），回到 Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 启用 **9go**。

> 升级时同样覆盖这三个文件即可。插件不写 `data.json` 之外的东西，升级不会动你的设置。

### 方式二：BRAT（跟随仓库）

安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 后，在 BRAT 里添加仓库 `greatooo/9go`，即可自动跟随 Release 更新。

## 九宫格怎么排

```
        [8] [1] [2]        1.1  1.2  1.3
        [7] [C] [3]   →    1.4   C   1.5
        [6] [5] [4]        1.6  1.7  1.8
```

- **中心格** = 当前中心节点，默认是笔记标题（文件名），可改成「第一个一级标题」；显示标题、备注与「返回上级」。
- **环绕 8 格** = 中心节点的下一级节点，默认从**正上方为第 1 个**、**顺时针**填满；左上角是第 8 个。第 1 个节点的方位与顺 / 逆时针都能在设置里改，格子左上角的编号随之同步变化。
- **层级映射**：笔记标题 → `# 一级`（环绕）；点某格的「下级 N」以它为中新中心 → `## 二级` 成为环绕 → 依此类推；列表项作为更深层的节点。
- 每格第一行是节点核心词，备注默认隐藏；可在设置里全局打开，也可点格子右下角 `⌄` 单独展开。
- 右上角的 `1.1`–`1.8` 是固定的格位坐标标签，默认不显示，避免和层级编号混淆。

### 编号规则

| 当前层 | 例子 | 显示编号 |
|---|---|---|
| 一级 | `# 一级1` `# 一级2` | `1` `2` |
| 二级 | `## …` | `1.1` `1.2` |
| 三级 | `### …` | `1.1.1` `1.1.2` |
| 四级及以上 | `1.1.1.1` | `1...1.1`（首段 + `...` + 末两段） |

编号是**全局同级序号**：翻到第 2 页继续 `9`、`10`…，不会每页从 1 重来。

## 触发方式

| 方式 | 写法 |
|---|---|
| frontmatter | `mandala: true` 或 `mindmap-structure: mandala` |
| 行内标记 | `%%mandala%%` |
| 内嵌代码块 | ` ```mandala ` 块内写同样的 Markdown 大纲（阅读模式内嵌渲染） |
| 命令面板 | 「以九宫格（Mandala）打开当前笔记」/「九宫格：把当前标签切换为 Mandala 视图」 |
| 文件右键 | 「以九宫格（Mandala）打开」 |

两条命令指向同一视图，区别只是**新开标签**还是**就地替换当前标签**：
想做「一边九宫格、一边 Markdown」的联动就选前者；只想换一种方式读同一篇笔记就选后者。

关键词默认 `mandala`，可在设置里改或追加（逗号分隔）。开启「自动打开标记笔记」后，打开带关键词的笔记会把该标签切成九宫格（每个文件每会话最多一次，避免来回切换）。

## 交互一览

| 操作 | 结果 |
|---|---|
| **双击空格** | 新建子节点：填标题 + 备注，按当前层级写回笔记，追加为最后一个子节点 |
| **双击已填充格** | 编辑该节点的标题与备注（可在设置里改回「双击 = 下钻」）；`✎` / `⤵` 按钮触发另一种操作 |
| **单击节点** | 在分屏的 Markdown 里定位到对应行，并像搜索结果一样高亮后淡出（时长可设 300–10000 ms） |
| **拖动子节点到同级两格之间** | 调整同级顺序，连整段子树一起写回 Markdown；放置时显示 L 形插入线 |
| **拖动子节点到中心格** | 该节点上升一级，成为与中心同级的下一个兄弟 |
| **`↗`** | 强制在 Markdown 中打开并定位 |
| **光标跟随**（可选） | 分屏编辑 Markdown 时，光标所在节点自动成为九宫格中心并高亮（250 ms 轮询） |
| **第 9–16 个节点** | 序列末格常驻「更多子节点」入口，翻页继续；新建节点总排在最后一个有内容节点之后 |

内嵌的 ` ```mandala ` 代码块没有可写文件，因此只读、不启用拖动与新建。

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 触发关键词 | `mandala` | 逗号分隔，匹配 frontmatter 键 / 值、`%%标记%%` |
| 自动打开标记笔记 | 开 | 打开带关键词的笔记时自动切为九宫格 |
| 默认显示备注 | 关 | 开后每格显示截断备注（含中心格）；中心格可用 `⌄ / ⌃` 单独覆盖 |
| 备注最大字数 | 120 | 超出以 `…` 截断 |
| 中心格标题来源 | 笔记标题（文件名） | 可改为「第一个一级标题」，只影响显示文字 |
| 自动折叠单根 | 关 | 笔记只有一个 H1 时，以该 H1 为中心显示其 H2 |
| 内嵌九宫格高度 | 460 px | ` ```mandala ` 块的高度 |
| 新建节点 · 备注写法 | 引用块 | 列表节点的备注自动多缩进一层，不打断下级列表 |
| 单击节点联动 Markdown 分屏 | 开 | 单击跳转 + 高亮后淡出 |
| 高亮持续时间 | 1400 ms | 300–10000，回车或点到别处生效 |
| 无分屏 Markdown 时 | 自动分屏 | 自动分屏 / 新标签 / 不处理 |
| 第 1 个子节点的位置 | 上（正上方） | 8 个方位任选 |
| 子节点排序方向 | 顺时针 | 顺时针 / 逆时针 |
| 显示格位坐标标签 | 关 | 右上角显示固定的 1.1–1.8 |
| 拖动调整同级顺序 | 开 | 拖到两格之间插入；拖到中心格 = 上升一级 |
| 光标跟随 | 关 | 光标移动时中心跟着切换 |
| 光标所在节点没有下级时 | 回退到父级 | 回退到父级 / 仍以该节点为中心 |

## 与 gogoga-mindmap 的关系

两者共用同一套笔记写法，因此**同一篇笔记可以互相对照阅读**：

- `#` = 中心，`##` / `###` = 分级；
- 列表项 = 更深的节点；
- `Tab` 缩进的一行 = 上一个节点的备注；
- 行内 `%%标记%%` / frontmatter 控制是否以九宫格打开。

差异在于 9go 是独立视图：不改原插件、不抢注册项，可以**同时启用**。若你已经在用 gogoga-mindmap，9go 只是给同一批笔记多一个 3×3 视角。

**参考实现**：[JackWeiGogoga/gogoga-mindmap](https://github.com/JackWeiGogoga/gogoga-mindmap) —— 九宫格语法与交互思路的来源，想看原始实现与完整语法说明请移步该仓库。

## 已知限制

- 备注以纯文本显示（不渲染 Markdown），wikilink 只显示别名文字、不可点击。
- 节点改动后由 `vault.on("modify")` 400 ms 防抖重绘；若同时插删行导致行号整体偏移，下钻层级可能回退到能匹配的最深一层。
- 光标跟随基于 250 ms 轮询**活动** Markdown 视图：切到别的笔记或处于阅读模式时暂停。
- 编辑节点会重写备注区：其中的普通正文 / 图片 / HTML 注释会被当作备注一并重写；围栏代码块、水平线与结构行不动。
- 新建节点只能追加为当前中心的最后一个子节点；要落到某个具体格位需手动调顺序。
- 序号超过 3 层的压缩是有损的：不同深层路径可能显示相同的「首段…末两段」。
- 拖动只在**当前页可见**的同级节点之间生效，跨页需先翻页。

## 开发

```bash
# 依赖：Node 18+ / esbuild
npm install

# 构建到 Obsidian 插件目录（默认 E:/OObsidian/.obsidian/plugins/9go）
npm run build

# 或指定输出目录
NINEGO_OUT=/path/to/vault/.obsidian/plugins/9go node build.js

# 回归测试
npm test     # test_core / test_grid / test_real_note
```

- `build.js` 用 esbuild 打包 `main.ts`，并把 `manifest.json`、`styles.css` 一并复制到输出目录；同时生成 `.core-test-bundle.cjs` 供 Node 侧跑纯函数测试。
- 三套测试当前为 **81 / 70 / 10**。`test_real_note.cjs` 依赖库内的真实样本笔记，缺少样本时会自动跳过相应用例。
- 改完 `main.js` 后必须**完全退出 Obsidian** 再重开（托盘 Quit），否则仍在跑旧代码。
